Cómo funciona Git

Una guía corta para entender la idea y los comandos básicos.

1. ¿Qué es Git?

Git es un sistema de control de versiones. Guarda "fotos" (llamadas commits) de tu proyecto a lo largo del tiempo, para que puedas:

  • Volver a una versión anterior si algo se rompe.
  • Ver quién cambió qué y cuándo.
  • Trabajar en paralelo con otras personas sin pisarse.

2. Las tres zonas

Todo cambio pasa por tres lugares antes de quedar guardado:

Directorio de trabajolos archivos que editás
git add →
Staginglo que vas a guardar
git commit →
Repositoriohistorial de commits

Pensalo como una foto: git add elige quién sale en la foto, git commit la saca.

3. El historial y las ramas

Cada commit apunta al anterior, formando una cadena. Una rama (branch) es una línea de trabajo separada: podés probar algo nuevo sin tocar la rama principal (main) y después unirla con git merge.

4. Local y remoto

Tu repositorio vive en tu computadora (local). Para compartirlo se usa una copia en un servidor (remoto), por ejemplo GitHub.

  • git push — sube tus commits al remoto.
  • git pull — baja los commits nuevos de otros.
  • git clone — copia un repositorio remoto a tu compu por primera vez.

5. Un ejemplo de principio a fin

# Crear un repositorio nuevo
git init

# Ver qué cambió
git status

# Preparar y guardar un cambio
git add index.html
git commit -m "Agrego la página principal"

# Crear una rama, trabajar en ella y volver
git switch -c nueva-funcion
#   ...editar archivos, add, commit...
git switch main
git merge nueva-funcion

# Ver el historial
git log --oneline --graph

# Compartir con el remoto
git push

6. Resumen de comandos

git initCrea un repositorio en la carpeta actual.
git statusMuestra qué archivos cambiaron y cuáles están en staging.
git add <archivo>Pasa cambios al staging (git add . agrega todo).
git commit -m "msg"Guarda una foto del staging con un mensaje.
git logLista el historial de commits.
git switch -c <rama>Crea una rama nueva y se mueve a ella.
git merge <rama>Une otra rama a la rama actual.
git pull / git pushBaja / sube cambios del remoto.
